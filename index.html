    Work in progress · UI/UX concept

    AquaPoint: reporting broken water points

    My next project is a UI/UX concept for SDG 6: Clean Water & Sanitation. I'm designing it in Figma. It's a simple mobile flow that would let anyone report a broken communal tap or borehole so maintenance teams hear about it sooner.

    6.1 The SDG target to give everyone safe, affordable drinking water.
    80% The estimated share of the world's water-collection burden carried by women and girls (FairAction).

    What I'm exploring

    • Icon-first fault reporting for low-literacy users
    • Offline drafts that sync when signal returns
    • Large touch targets and WCAG AA colour contrast
    • A simple status tracker so reporters can see that something happened

    This is a concept, not a shipped product. I haven't done user research or testing on it yet. Talking to community members is the next step.

    How I work

    Curious, evidence-led and honest about limits

    1. 01

      Understand

      Start with the business or human problem and the requirements before touching code or data.

      • Requirements analysis
      • Stakeholders
    2. 02

      Explore

      Clean the data and run exploratory analysis: duplicates, class imbalance, distributions and correlations.

      • pandas
      • EDA
      • Seaborn
    3. 03

      Build

      Engineer features and services in small, maintainable pieces using Git-based workflows.

      • TypeScript
      • Python
      • Git
    4. 04

      Evaluate

      Compare models, choose the right metric for the problem (like recall in health) and find what's breaking.

      • Recall
      • AUC-ROC
      • Debugging
    5. 05

      Document

      Write up the findings, limitations and next steps so the team can trust the work and build on it.

      • Docs
      • Agile
      • Knowledge sharing
